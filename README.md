# ÉLORA – Fashion E-Commerce Website

ÉLORA is a responsive fashion e-commerce website built using HTML, CSS, and JavaScript.

## Features
- Product listing using DummyJSON API
- Product search and category filtering
- Product details page
- Shopping cart with quantity management
- Wishlist functionality
- Checkout form with validation
- Order success page
- Order history management
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DummyJSON API
- LocalStorage

## Live Demo
https://fashion-store-cyan-xi.vercel.app/

## Note
This is a frontend demonstration project. Cart, wishlist, and orders are managed using browser LocalStorage. No real payments are processed.
